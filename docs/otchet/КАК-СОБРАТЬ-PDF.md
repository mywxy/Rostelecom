# Сборка PDF-отчёта (Симоненко Матвей)

## Оформление (по заданию)

| Элемент | Параметр |
|---------|----------|
| Шрифт | Times New Roman |
| Основной текст | 14 pt |
| Заголовки разделов | 16 pt, **полужирный** |
| Подписи к рисункам | 12 pt, по центру: **Рисунок X — описание** |
| Нумерация страниц | С **Введения** (титул и содержание без номера или римские — по шаблону курса) |
| Рисунки | По центру страницы |

## Порядок страниц

1. **Титульный лист** — шаблон от преподавателя (не из этого файла).
2. **Содержание** — автоматически в Word: «Ссылки» → «Оглавление».
3. Скопировать текст из **`ОТЧЕТ-Симоненко-Матвей.md`** начиная с «Введение».
4. В местах *[Вставить: Рисунок N]* — вставить PNG/JPG из **`screenshots/`**.
5. В §8 заменить ссылку GitHub на реальную.
6. **Файл → Сохранить как → PDF**.
